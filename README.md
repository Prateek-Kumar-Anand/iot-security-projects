# IoT Security Projects for ESP32 DevKit V1

This repository contains a collection of coding projects related to IoT security devices and embedded systems using the ESP32 DevKit V1.

## About

The repository is organized into multiple sub-folders to make it easier to locate and use the required `.ino` files. Each sub-folder focuses on a specific project category and contains one or more Arduino sketches.

## Features

- Projects developed for ESP32 DevKit V1
- Organized folder structure for easy navigation
- Multiple `.ino` files for different applications
- Detailed documentation inside each project folder
- Security-focused IoT and embedded system implementations

## Repository Structure

- Each project category is stored in a separate sub-folder.
- Every sub-folder contains the relevant `.ino` files.
- A dedicated `README.md` inside each sub-folder explains:
  - Project purpose
  - Required components
  - Wiring information
  - Usage instructions
  - Code description

## Note

Please refer to the README file inside each project folder for detailed information about the project and its implementation.
