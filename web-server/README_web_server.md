# ESP32 Web Server Projects

This folder contains a collection of web server-based projects developed for the ESP32 DevKit V1.

## Overview

The projects in this folder focus on using the ESP32 as a web server. Most examples can be accessed directly through a web browser connected to the same network as the ESP32.

## Included Projects

### Advanced Graphing Calculator
- Browser-based calculator
- Advanced mathematical calculations

### Picture on Web Server
- Displays images through a browser
- Demonstrates media serving using ESP32

### Temperature and Humidity Monitor
- Environmental monitoring dashboard

### Trigonometry Ratio Calculator
- Browser-based trigonometric calculations

### GIF Display on ESP32
- Animated content demonstrations

### ESP32 Motor Web Control
- Remote control of motors and devices

### ESP32 Tic-Tac-Toe
- Interactive browser-based game

### Offline Web Server
- Local network web applications

### OTA Update
- Wireless firmware updates

### Password Saving Server
- Form handling and server-side processing examples

## Requirements

### Hardware
- ESP32 DevKit V1
- USB Cable
- Wi‑Fi Connection

### Software
- Arduino IDE or Arduino Cloud
- ESP32 Board Package
- Required Libraries

## Uploading the Code

1. Download the desired `.ino` file.
2. Open it in Arduino IDE or Arduino Cloud.
3. Select **ESP32 DevKit V1**.
4. Install required libraries.
5. Compile and upload.

## Notes

- Some projects require additional hardware.
- Check source code comments for specific instructions.
- Wi‑Fi credentials may need modification before uploading.
