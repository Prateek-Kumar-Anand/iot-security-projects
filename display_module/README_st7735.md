# ST7735 Display Projects

This folder contains projects and examples developed using the ST7735 display module with the ESP32 DevKit V1.

## About

The codes provided in this folder are designed for the ST7735 display module. However, most of them can be modified and adapted for other compatible display modules as required.

The collection includes:

- Beginner-friendly projects
- Intermediate-level projects
- Advanced and complex implementations

## Uploading the Code

For the best experience, it is recommended to use Arduino Cloud for compiling and uploading the code.

### Steps

1. Create an Arduino Cloud account.
2. Download the desired `.ino` file from this folder.
3. Upload the file to Arduino Cloud.
4. Compile the project and select **ESP32 DevKit V1** as the target board.
5. Click the **Upload** button to flash the code to your device.

## Requirements

- Arduino Cloud Agent installed
- Required ESP32 drivers installed
- ESP32 DevKit V1 connected properly
- Necessary libraries installed

## Note

Each project may require additional libraries or hardware components. Please check the comments inside the source code for project-specific requirements.
